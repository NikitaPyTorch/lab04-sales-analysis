# Построчный разбор для защиты ЛР № 4

Номера сверены с исходниками этого проекта. Разбор охватывает четыре Java-файла и `pom.xml`: **225 строк Java и 37 строк XML**. Импорты, пустые строки и закрывающие скобки объясняются группами; строки с действиями — отдельно либо короткими диапазонами.

Чтобы подготовиться, сначала прочитай `Sale`, затем `DemoData`, после них `SalesAnalyzer` и `Application`. На защите показывай конкретную строку и объясняй, какое значение она получает и что возвращает.

## Небольшой словарь перед разбором

| Запись | Как объяснить своими словами |
|---|---|
| `public` | Доступно вызывающему коду других классов |
| `private` | Используется только внутри этого класса |
| `static` | Принадлежит классу: можно вызвать через его имя, не создавая объект |
| `final class` | От класса нельзя наследоваться |
| `final` у поля | После присваивания поле нельзя переназначить; само по себе это ещё не делает любой объект неизменяемым |
| `void` | Метод не возвращает значение |
| `List<Sale>` | Список, элементы которого имеют тип `Sale` |
| `Map<String, List<Sale>>` | Карта: строковый ключ и список продаж в качестве значения |
| `new ArrayList<>()` | Создать список; тип в `<>` компилятор выводит из контекста |
| `return` | Вернуть значение и завершить метод |
| `sale -> ...` | Лямбда: правило обработки одного переданного элемента |
| `Sale::getAmount` | Ссылка на метод: вызвать `getAmount()` у обрабатываемого объекта продажи |
| `&&` / `\|\|` / `!` | Логические «и» / «или» / «не» |
| `{ ... }` | Блок класса, метода, условия или цикла |

У `&&` и `||` короткое замыкание: второе условие вычисляется только тогда, когда нужно определить общий результат. Например, при `value == null || value.isBlank()` у `null` метод `isBlank()` не вызывается.
